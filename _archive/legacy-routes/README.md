# Legacy routes (archived 2026-10-06)

esy.com became The Marketing Engineer on 2026-09-13. These routes came from
earlier eras of the site: the visual-essay library, the student-writing SEO
pages, and the product catalog. None of them were linked from the live header,
footer or homepage any more. They were archived here instead of deleted, so
any of them can be brought back without digging through git history.

`_archive/` is excluded from `tsconfig.json`, so nothing in here is built,
routed or typechecked. The old URLs answer **410 Gone** from
`src/middleware.ts`, using the list in `src/lib/retired-routes.ts`. They are
also out of the sitemap, and the redirects that only moved them between
folders are gone.

## What's here

| Path | Was | Why it went |
|---|---|---|
| `essays/` | `/essays/*`: ~100 visual essays (etymology, history, science, food, inventions, children's stories, writing guides) | Off-brand for the publication. `/essays` comes back as AI marketing and tech visual essays |
| `content/essays/` | 3 markdown essays at `/essays/[id]` | Same |
| `visual-essays/`, `scrollytelling/`, `photo-essays/` | Showcase pages for the essays above | Only existed for the old essays |
| `how-to-write/`, `how-to-write-an-essay/`, `writing-prompts/` | Student-writing SEO pages | School era |
| `theme-comparison/` | Developer page comparing two old homepages | Leftover, and it was in the sitemap |
| `artifacts/`, `clip-art/`, `infographics/` | Product-catalog hub and detail pages | Product era; clip.art is its own site |
| `models/` | "Models used in Esy workflows" reference | Product era |
| `roadmap/` | Public roadmap | Only linked from an unused footer |
| `agentic-workflows/` | Single SEO guide page | Only linked from a dead landing page |
| `src/` | Components and libraries only these routes used, at their original paths | Orphaned by the move |
| `public/` | The essays' images and OG cards, at their original paths | ~100 MB that no live page served |

## Deliberately kept live

- **`/essays` itself.** The namespace returns with new essays. Only the old
  essays' first path segments are retired, so new essays must not reuse a
  slug listed in `RETIRED_ESSAY_SLUGS`.
- **The visual-essay pipeline's runtime:** `src/components/ArtifactDetail`,
  `src/components/InlineIntelligence`, `src/lib/insights`,
  `src/lib/visual-essay-metadata.ts`, `src/lib/models` and
  `src/data/visualEssays.ts`. Pages generated by `orchestration/` import
  these, and the new essays may still come out of that pipeline.
- **`/glossary`,** which is being reshaped into an AI marketing glossary.

## To bring a route back

1. `git mv _archive/legacy-routes/<route> src/app/<route>`, and move back any
   files it needs from `_archive/legacy-routes/src/` and
   `_archive/legacy-routes/public/`.
2. Remove the route from `src/lib/retired-routes.ts` and from the matcher in
   `src/middleware.ts`.
3. If it has dynamic pages, add them back to `src/app/sitemap.ts`.
