# Brand

How Esy looks and sounds wherever it shows up: the site, YouTube, social.
Brand canon that binds every Esy repo is also kept in org.esy (`brand/`); a
copy lives here so it sits next to the site and the work that uses it.

| Doc | What it covers |
| --- | --- |
| [ESY_DEFINITION.md](ESY_DEFINITION.md) | Pointer: the brand definition lives in org.esy (`brand/ESY_DEFINITION.md`). |
| [YOUTUBE_THUMBNAILS.md](YOUTUBE_THUMBNAILS.md) | The two thumbnail templates (Desk, Room), the rules, the face set and every 3D logo, with their Esy runs. Also in org.esy. |

`img/` holds the pictures these docs show.

Docs that live in this repo should be kept in step with their org.esy copy
when they change.
